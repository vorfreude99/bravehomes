Colour

Brass is reserved for money and progress — never decoration. The two “ink” shades exist because the display greens and brass drop below 4.5:1 at label sizes.

Typography

Newsreader for display at 400–500 only; Public Sans for everything else. Public Sans was drawn for government services with legibility as the brief, which is the same problem this product has.

The signature animation

A scroll value is written to one CSS variable each frame; every word derives its own progress from it and the highlight sweeps across. Drag the slider to scrub it.

Easy View

A real mode, not a zoom. It raises the root font size, grows every tap target, thickens focus rings and hides decorative motion — one attribute on <html> scales the whole interface.
